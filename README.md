# Client Query Management System 🚀

A modern, full-stack ticketing and support dashboard built using **Streamlit**, **PostgreSQL**, **Python**, **Pandas**, and **Plotly** — designed to streamline client issue tracking and support management.

## Project Overview

The **Client Query Management System** provides an intuitive and centralized platform for clients to raise support queries and for support teams to manage, resolve, and analyze them efficiently.

With **role-based login**, **smooth UI**, **dynamic visual dashboards**, and **CSV analytics for large datasets (5000+ records)**, CQMS is built for **clarity**, **performance**, and **modern user experience**.

**Transforms chaotic email threads → structured, actionable data insights.**

---

## 🎯 Problem Statement

**Real-time interface** for clients to submit queries and support teams to manage efficiently:
- **Current**: Static CSV logs, scattered emails 
- **Now**: Dynamic **PostgreSQL** environment with live metrics
- **Impact**: Faster communication, better resolution accuracy, full transparency

---

## ✨ Key Features

- **🔐 Secure Role-Based Login** (Client/Support/Admin)
- **👤 Client Portal**: Create tickets + "My Tickets" view
- **🛠 Support Dashboard**: Assign/track/update/close
- **📊 Admin Analytics**: Volumes, SLAs, trends, workloads
- **⚡ High Performance**: Handles 5,000+ records seamlessly
- **📈 Interactive Charts**: Plotly dashboards for insights
